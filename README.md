# Zodiac Daily Native

Independent iOS app for a brief, editorial daily horoscope ritual. The working
public name is **Zodiac Daily** and the internal project name is
`ZodiacDailyNative`.

The current milestone combines visual direction with non-visual core work.
Final layout, art, and visual experience remain blocked until the owner
explicitly approves the relevant complete screen image; engine, data,
persistence, tests, build setup, and documentation may advance in parallel.

## Current status

- Product: MVP defined for iPhone, English only.
- Visuals: three initial Today directions plus a collectible-card revision await
  owner approval.
- Code: non-visual Swift core package implemented; final UI is not started.
- External services: none.
- GitHub: private repository pending explicit authorization.

See `docs/MVP.md`, `docs/VISUAL_FIRST.md`, and `docs/TECHNICAL_SETUP.md`.
